# Website Nembak Pacar 💖 - Put Us Back Together (Devia / Via)

Website interaktif romantis untuk menyatakan perasaan (nembak pacar) dengan game puzzle Hati interaktif, musik *About You - The 1975*, animasi kelopak bunga sakura, dan **Notifikasi Realtime ke Discord Webhook**!

![Preview](assets/heart_puzzle.svg)

## 🌟 Fitur Utama
- 💌 **Opening Envelope**: Amplop 3D pembuka surat romantis.
- 💬 **Pesan Proposal Khusus**: Ditunjukan untuk Devia (Via) dengan kalimat percakapan manis.
- 🧩 **6-Block Heart Puzzle Matrix**: Game susun 6 kepingan Hati Merah (*IYA, AKU MAU! DITERIMA 🥰*).
- 💔 **Tombol Tab Hati Retak**: Peringatan lucu jika doi mencoba mengeklik tab Hati Retak.
- 🔔 **Integrasi Discord Webhook**: Notifikasi langsung ke server Discord kamu saat doi menerima atau mengeklik Hati Retak!
- 🥳 **Confetti & WhatsApp Direct**: Pesta kembang api dan tombol balasan langsung terhubung ke WhatsApp.

## 🚀 Cara Menjalankan
Buka file `index.html` langsung di browser kamu!

## ⚙️ Pengaturan
Klik ikon pensil di pojok kiri atas untuk mengubah:
- Nama Panggilan Doi (Default: Via / Devia)
- Nama Pengirim
- Nomor WhatsApp
- URL Discord Webhook
- Link Musik MP3
